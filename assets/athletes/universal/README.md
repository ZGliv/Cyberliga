# Cyberliga universal athlete source

The male and female humanoid base meshes are the free **Universal Base Characters (Standard)** pack by Quaternius, downloaded from the creator's official itch.io release and distributed under CC0 1.0. The original license text is preserved in `LICENSE.txt`.

Cyberliga uses these 13k-triangle, humanoid-rigged glTF files as the authored production-mesh path. Texture maps have been resized for web delivery; geometry, skeleton names, and UVs remain unchanged. The procedural athlete remains the deterministic runtime fallback while the shared soccer action library is retargeted to this skeleton.

Source: https://quaternius.com/packs/universalbasecharacters.html
