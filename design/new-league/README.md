# Cyberliga / A new league

Design review package - September 6, 2026.

## Status and scope

The user approved a fresh product and visual design package before application implementation. This directory proposes a new direction. It does not modify or replace the current six-sport application, authorize deployment, or establish that any visual study is a functioning game.

The codebase, six-sport structure, current clubs, capsule renderer and existing navigation are not creative constraints for this proposal. The branch starts from the canonical HEAD only to preserve safe repository provenance. Current production remains untouched.

**Product premise:** A fictional league where you learn the players, pick a side, and watch competition create its own stories.

**Reference format:** autonomous 3v3 half-court basketball, portrait first. Initial motion and competition prototype: two clubs, six athletes, one court. First small league, only after validation: four clubs and twelve athletes.

## Deliverables

- `output/pdf/cyberliga-new-league-design.pdf`: visual review dossier.
- `assets/`: generated art-direction, cast and court studies; concepts only.
- `prompts.json`: exact prompts, input references, generation method and output provenance.
- `brief.md`: product, cast, camera, motion, rules and implementation criteria.
- `build_package.py`: reproducible PDF authoring source.

Generated images use the built-in image-generation tool. They are raster concept studies, not finished models, production assets, gameplay footage or verified performance evidence. Names and marks are provisional and have not been cleared for commercial use. Numbers, score states and sequences in the mockups are illustrative.

## Review decision

Judge the recommended visual direction, the six-person cast, and the portrait court composition. After creative direction is accepted, the next bounded implementation would be a motion study and a simple autonomous possession prototype. Full application rebuild, expanded league content and wagering integration remain later stages.
